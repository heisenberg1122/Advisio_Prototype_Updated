## Seed gaps and integration limits

Runtime verification found that the current Documents feedback UI reads reviewer assignments, so the v1 legacy comments are not displayed there; the prepared revision guidance is visible on the task detail. All records are fictional, including evaluation.invalid addresses.

Absent: second project, pending group/workflow invitations, workspace-only onboarding records, shared folders/files, chat history, inbox correspondence, completed consultations, notes/transcripts, Google connection, official copies, Researcher defense session, published defense result/badges and class/defense grades. Capture may create shared files through normal UI and resubmit the supplied revision only within its own temporary workspace. It must not change the seed or access controls to populate missing outcomes.

Evaluation configuration explicitly requires local storage, disabled email and absent external Google/Resend/Supabase credentials. Meet connection UI accepts a URL; it is not proof of OAuth connection or automatic transcription. Some old copy claims otherwise; narration follows implemented behavior instead.
