# ADVISIO Researcher Guide

A guided tour of the Researcher workspace and its core features. Demonstrations use fictional research records.

## 0. Introduction

A guided tour of the Researcher workspace and its core features. The demonstration uses fictional research records.

Optional activity: Open the Researcher workspace.

## 1. Researcher overview

Inspect the active project, current stage, milestone progress, pending requirements, consultation summary and recent activity.

Optional activity: Locate the current milestone.

## 2. My Project

Review project details, adviser and workflow. My Group shows membership and leader information. Access and adviser actions depend on project status and your role.

Optional activity: Open My Group and inspect the roster.

## 3. Tasks and requirements

Read task statuses, deadlines and instructions. Open a task to inspect its submission, faculty guidance and milestone context.

Optional activity: Open Revised research proposal.

## 4. Documents and revision submission

Compare preserved document versions and their review context. Working-file uploads and formal task submissions are separate actions. A submission records the version sent for faculty review.

Optional activity: Inspect a version, then review the related task submission.

## 5. Group Files

Use folders to store shared project material. Adding a shared file does not submit a requirement.

Optional activity: Open a folder and inspect its files.

## 6. Timeline and milestones

The timeline reflects the configured workflow, with completed, current and future stages. Review gates and prerequisites determine progression.

Optional activity: Compare the current milestone with the next stage.

## 7. Defense

Inspect defense readiness and requirements. A session, panel, published manuscript and results appear when available to the project.

Optional activity: Inspect the current defense state.

## 8. My Grades

Class Grades and Defense Grades display records according to publication and release rules.

Optional activity: Inspect the release state in each view.

## 9. Consultations

Inspect scheduled consultations and the request form. Notes and chat import are separate from joining a connected meeting.

Optional activity: Open the available consultation record.

## 10. Calendar

Inspect authorized events for the selected period and open an event to read its details.

Optional activity: Find a consultation or task deadline.

## 11. Messages and Inbox

Messages contains conversations and invitations. Inbox contains correspondence threads, drafts and folders. Group conversation creation is a faculty control.

Optional activity: Compare Messages with Inbox.

## 12. Notifications, profile and settings

Review notification read states and destinations. Profile contains account information; Settings includes appearance and browser-local notification preferences.

Optional activity: Open a notice, then locate Appearance.

## 13. Researcher Walkthrough Complete

The Researcher walkthrough is complete. Return to any chapter for a refresher while using ADVISIO.

Optional activity: Explore the Researcher workspace.
